    Nmap Cheatsheet

    Scan Types
    Scan-sSSYN scan (stealth) — sends SYN, does not complete the handshake. Faster and stealthy.
    Scan-sTTCP connect scan — completes full handshake. Used without root privileges.
    Scan-sUUDP scan — detects UDP services (DNS, SNMP, DHCP...).
    Scan-sN / -sF / -sXNull, FIN, and Xmas scan — evades some firewalls, ambiguous behavior on Windows.
    Scan-sAACK scan — detects firewall rules rather than open ports.
    Scan-sVService version detection on open ports.
    Scan-OOperating system detection via TCP/IP fingerprinting.
    Scan-AAggressive mode: OS detection, versioning, scripts, and traceroute all at once.
    Host Discovery & Ports
    Host/Port-p <ports>Defines which ports to scan. Ex: -p 80,443 / -p 1-1000
    Host/Port-p-Scans all 65,535 ports.
    Host/Port--top-ports NScans the top N most common ports.
    Host/Port-snPing scan — only discovers hosts without scanning ports.
    Host/Port-PnSkip host discovery — treats all targets as online.
    Host/Port-PRARP ping — host discovery on local networks, highly reliable.
    Host/Port--openShows only open ports in the output.
    Host/Port-iL <file>Reads target list from a text file.
    Timing & Performance
    Timing-T0 ... -T5Scan speed. T0=paranoid (stealthy), T3=normal, T5=insane.
    Timing--min-rate NForces a minimum of N packets sent per second.
    Timing--max-retries NLimits retries per port (useful to speed up scans).
    Timing--host-timeoutAbandons a host if it takes longer than X time. Ex: 30s
    Nmap Scripting Engine (NSE)
    NSE-sCRuns default NSE scripts (equivalent to --script=default).
    NSE--script=<name>Runs a specific script. Ex: --script=vuln
    NSE--script-argsPasses arguments to scripts. Ex: user=admin
    NSE--script-helpShows help for a specific script.
    Evasion & Spoofing
    Evasion-fFragments packets to evade IDS/IPS.
    Evasion-D <decoys>Decoy scan — mixes your IP with decoy IPs to confuse logs.
    Evasion--source-port NForces the source port. Firewalls often trust ports 53 or 80.
    Evasion--scan-delayAdds a delay between probes to avoid rate-limiting alerts.
    Output Formats
    Output-oN <file>Saves output in normal (readable) format.
    Output-oX <file>Saves in XML format — compatible with Metasploit.
    Output-oG <file>Grepable format — easy to parse with grep/awk.
    Output-oA <base>Saves in all three formats simultaneously.
    Host Discovery / Local Network Recon
    root@kali:~#nmap -sn 192.168.1.0/24
    root@kali:~#nmap -sn -PR 192.168.1.0/24
    Discovers active hosts without scanning ports. -PR uses ARP (highly reliable on LAN). Ideal for the initial phase of an internal pentest.
    Fast Port Scanning Basic
    root@kali:~#nmap -sS -T4 --top-ports 1000 -Pn 10.10.10.5
    root@kali:~#nmap -sS -p- --min-rate 5000 -Pn -n 10.10.10.5
    The second command scans all 65,535 ports at high speed. -n disables DNS resolution for faster execution. Heavily used in CTFs and HTB labs.
    Version & OS Detection Basic
    root@kali:~#nmap -sV -O -sC 10.10.10.5
    root@kali:~#nmap -A -p 22,80,443,8080 10.10.10.5
    -sV fingerprints the service, -O detects the OS, -sC runs default scripts. -A bundles everything. Essential step after the initial port scan.
    SMB Enumeration NSE
    root@kali:~#nmap -p 139,445 --script=smb-os-discovery 10.10.10.5
    root@kali:~#nmap -p 139,445 --script=smb-enum-shares,smb-enum-users 10.10.10.5
    root@kali:~#nmap -p 445 --script=smb-vuln-ms17-010 10.10.10.5
    Detects SMB version, available shares, users, and critical vulnerabilities like EternalBlue (MS17-010). Mandatory in Windows/Active Directory environments.
    HTTP / Web Enumeration NSE
    root@kali:~#nmap -p 80,443,8080 --script=http-title,http-headers 10.10.10.5
    root@kali:~#nmap -p 80 --script=http-enum 10.10.10.5
    root@kali:~#nmap -p 80 --script=http-methods 10.10.10.5
    http-enum performs common path fuzzing (similar to a basic gobuster). http-methods detects dangerous HTTP verbs (PUT, DELETE).
    Database Enumeration NSE
    # MySQL
    root@kali:~#nmap -p 3306 --script=mysql-info,mysql-empty-password 10.10.10.5
    # MS-SQL
    root@kali:~#nmap -p 1433 --script=ms-sql-info,ms-sql-empty-password 10.10.10.5
    Checks for basic database information and attempts to find accounts with blank passwords.
    FTP / SSH / RDP NSE
    root@kali:~#nmap -p 21 --script=ftp-anon,ftp-bounce 10.10.10.5
    root@kali:~#nmap -p 22 --script=ssh-auth-methods 10.10.10.5
    root@kali:~#nmap -p 3389 --script=rdp-vuln-ms12-020 10.10.10.5
    ftp-anon detects if the FTP server allows anonymous login. rdp-vuln checks for a critical DoS/RCE vulnerability.
    Vulnerability Scanning Vulns
    root@kali:~#nmap -sV --script=vuln 10.10.10.5
    root@kali:~#nmap -sV --script=exploit 10.10.10.5 --script-args=unsafe=1
    The vuln category runs all CVE detection scripts. The unsafe=1 argument enables potentially intrusive scripts — use only in controlled environments.
    UDP Scan UDP
    root@kali:~#nmap -sU -p 53,67,68,161,500 10.10.10.5
    root@kali:~#nmap -sU -p 161 --script=snmp-info 10.10.10.5
    UDP scanning is slow — limit the target ports or use --top-ports. SNMP (161) often reveals critical network/system info.
    Firewall / IDS Evasion Evasion
    root@kali:~#nmap -sS -f -T2 --data-length 200 -D RND:10 10.10.10.5
    root@kali:~#nmap -sS --source-port 53 -Pn 10.10.10.5
    -f fragments packets, -D RND:10 generates 10 random decoy IPs, --source-port 53 mimics DNS traffic. Combining techniques increases evasion success.
    Full Workflow (CTF / Pentest) Workflow
    # Phase 1: Fast all-ports discovery
    root@kali:~#nmap -sS -p- --min-rate 5000 -Pn -n -oN ports.txt 10.10.10.5
    # Phase 2: Deep dive into open ports
    root@kali:~#nmap -sV -sC -O -p 22,80,445 -oA full_scan 10.10.10.5
    # Phase 3: Targeted scripts based on findings
    root@kali:~#nmap -p 445 --script=smb-vuln-ms17-010 10.10.10.5
    Standard methodology: speed → depth → targeted scripts. Always save your output using -oA or -oN for later review.
